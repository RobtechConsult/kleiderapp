# u2netp.onnx

Salient-object segmentation model used for background removal in the web version.

- Model: U²-Net-P from "U²-Net: Going Deeper with Nested U-Structure for Salient Object Detection"
  (Qin et al.), https://github.com/xuebinqin/U-2-Net — Apache License 2.0
- ONNX export: from the rembg project, https://github.com/danielgatis/rembg — MIT License
  (release asset `v0.0.0/u2netp.onnx`)
